## Store Assets Starter Kit v0.2.0

This release expands the existing Microsoft Store listing-update workflow and adds safer validation, asset tracking, upgrades, and session handoff.

### Highlights

- Prepare listing-only updates without inventing a new application package version; package updates can continue with missing evidence recorded as pending.
- Create an independent Draft for each update and recover orphaned candidates only from confirmed task facts.
- Preserve immutable submission-attempt snapshots and distinguish store-event times from observation and recording times.
- Use the optional read-only Node.js 22+ checker to find structural issues, missing files, conflicting records, and historical-reference gaps.
- Track Microsoft Store Logo sources, exports, package-specific roles, and localized upload consumers in explicit inventories.
- Compare and merge kit upgrades while preserving local adaptations, current assets, candidates, and submission history.
- Continue work in a new session from saved records and evidence without inventing missing ownership, language, or publication facts.

### Verification scope

- The checker suite passed 71 tests. Constructed-artifact exercises passed 49 submission-history assertions, 56 upgrade/stamping assertions, and 36 session-handoff assertions.
- Ten selected independent workflow scenarios passed on 2026-10-23. They represent one execution set on one available executor; they do not establish repeated or cross-model reliability.
- Shared-inventory promotion and blocked-then-resumed upgrade variants were not independently exercised. No real Store upload or live-page review is claimed.
- The release asset will be checked against its tag, source commit, required package paths, and stamped provenance before publication.

### Upgrade note

For an existing project, follow `store-assets/upgrading.md`. Compare the incoming kit separately and merge local rules deliberately. Preserve customized rules, `current/`, `release-prep/`, submission records, and their historical Git references; do not replace them with the downloaded package.

### Download

Download `store-assets-starter-kit-v0.2.0.zip`, then copy its `store-assets/` folder into an application repository.
