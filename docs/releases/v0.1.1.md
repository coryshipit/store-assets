## Store Assets Starter Kit v0.1.1

This release clarifies and hardens Store Assets workflow foundations.

### Highlights

- Defines one independent `store-assets/` work package per application project.
- Supports updates to existing Microsoft Store listings only. An app's first store submission remains outside the workflow.
- Treats the store as a task-level adapter selection; `microsoft-store` is the only executable adapter in this release.
- Allows one active submission per store adapter at a time.
- Defines `release-prep/` as a complete candidate snapshot and replaces the corresponding `current/` locale tree after explicit go-live confirmation.
- Simplifies the submission status flow by removing `Ready for submission`.
- Uses the rulebook file skeletons as the Phase 1 source for listing, release-notes, and submission-record formats.
- Strengthens release packaging validation and prevents published Release assets from being overwritten.

### Upgrade note

For an existing project, merge the updated workflow and rulebook template deliberately. Do not overwrite generated rulebooks, `current/`, `release-prep/`, or `submissions/` blindly, because they contain project-specific or historical records.

### Download

Download `store-assets-starter-kit-v0.1.1.zip`, then copy its `store-assets/` folder into an application repository.
